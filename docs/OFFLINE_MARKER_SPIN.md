# 连续标记轨迹的离线转速估计

入口 `python pingpong.py spin --output output/spin_new`，实现 `marker_spin.py`，复用上游 `spin.solve_constant_sphere_rotation`。已对现有轨迹和整批重新推理结果运行，审核入口 `output/latest/spin/review.html`。

## 计算

1. 读取三帧以上连续观测，核对图片、原始时间与球体支持状态，拒绝预测保持点和不连续段。
2. 由源裁剪倍率恢复球半径。256 像素、倍率 1.2 对应中心 (128,128)、半径约 106.6667，不能使用 128。CSV 标记点在裁剪坐标中，manifest 球心/半径在原传感器坐标中，不能混用。
3. 弱透视近似下，归一化点投到可见前半球：`p=(x,y,-sqrt(1-x²-y²))`。相机局部坐标 x 向右、y 向下、z 远离相机。
4. 每 20 ms 窗口、10 ms 步长，提取同段 1/2/4 帧的对应，最大间隔 2 ms。任一中间点为球体回退状态则不建立该对应。不跨身份配点。
5. 拟合角速度向量 `ω`，最小化 `R(ω·Δt)p(t)` 与 `p(t+Δt)` 的差。使用固定随机种子 RANSAC 和 soft-L1 稳健最小二乘求有限旋转。`RPM=||ω||×60/(2π)`，`RPS=RPM/60`。
6. 检查至少 8 对对应、6 个不同观测、2 ms 跨度、70% 内点、几何条件数、全点角残差、内点重投影 RMS 和混叠风险。三帧符合轨迹导出要求，不代表自动能可靠求解旋转。

参数见 `config/offline_marker_spin.json`。对应点共享观测，事件窗口和拟合窗口重叠，不输出虚假的独立样本数量或统计置信区间。

接口数学参考 [OpenCV Rodrigues](https://docs.opencv.org/4.6.0/d9/d0c/group__calib3d.html) 和 [SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)；这些文档不验证当前数据的实物精度。

## 输出

| 文件 | 内容 |
| --- | --- |
| `spin_report.json` | 方法/参数/输入哈希、时间和几何来源、角速度、局部旋转轴、拒绝原因与限制 |
| `spin_by_group.csv` | 分相机分发球的可用数量、中位数与范围，描述统计而非置信区间 |
| `spin_windows.csv` | 各窗口候选 RPM/RPS、质量、拒绝状态 |
| `spin_reprojection.csv` | 各时间对应的预测位置、观测位置、像素误差，含拒绝窗口诊断 |
| `spin_candidates.png` | 候选转速与窗口位置 |
| `*_reprojection.png` | 绿色观测框中心，红色从每段起点按模型预测；观察错配与累计漂移 |
| `review.html` | 无外部网络依赖的审核入口，需同目录 PNG/CSV/JSON |

`candidate_spin_rpm` 仅在数值检查通过时填写。失败窗口的 `raw_fit_rpm` 是诊断，不是有效结果。物理输入和独立真值尚未验证，因此 `spin_rpm=null`、`accepted=false`。低残差不能证明簇中心是同一物理点或时钟正确。

当前没有标定文件，使用弱透视；两路输出各自相机坐标轴下的向量，不融合。可见时段不同，组中位数不能直接平均。Kalman 框中心、事件拖尾和重叠 1 ms 窗口可能带来偏差。

## 后续优化顺序

1. **簇内中心**：用 YOLO 定位簇，再在未过滤极性/事件图中拟合物理标记中心。对照检测、光流、Kalman 与几何拟合中心的重投影误差，减少框形状和拖尾偏差。
2. **球体几何**：抽样核验球心/半径，量化裁剪抖动，再联合优化平移、半径和旋转。只加大轨迹平滑可能引入额外延迟。
3. **时间验证**：检查 SDK 单调性、窗口时刻定义和已知周期信号，并独立验证双机时间差。1 ms 窗口以 0.5 ms 步长生成，不是独立瞬时观测。
4. **透视和双目**：有内参、畸变、外参与时间差后，用 manifest 恢复传感器坐标，接入已有透视球面/stereo 求解器，在同一时刻和坐标系融合。
5. **刚体约束关联**：旋转预测反馈到追踪，用球面运动拒绝身份切换；不强行跨消失区域延续 ID。RANSAC 不能替代身份真值。
6. **实物评估**：已知转速电机/转台或高速参考相机，使用未参与调参的轨迹评估 RPM 相对误差、轴误差与有效覆盖率，同时报告残差，避免只挑容易窗口。

合成测试覆盖有限 3D 旋转恢复、时间缩放、错误身份稳健剔除、退化几何、三帧不自动可测、清单时间错位、预测点和回退跨接拒绝。合成测试验证数学行为，不代表实物精度验证完成。
