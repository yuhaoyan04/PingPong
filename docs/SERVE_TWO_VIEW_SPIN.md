# 逐次发球、零转速与双视角互补

审核入口：`output/latest_serve/review.html`；可下载 `output/latest_serve/serve_review_bundle.zip`。

## 0 是合法下限

此前的 18.8–50.0 RPS 是当前数据中数值可用窗口的观测范围，不是允许范围，也不是验收下限。弱旋转与不转发球允许从 0 开始。转速为角速度的模，方向由有符号的三维角速度表示。

检查发现通用 SO(3) RANSAC 评分核跳过了恰好为零的角速度。本轮保留并显式加入恒等旋转假设，直接对零旋转计算共识，修复这一问题。合成 0、0.05、0.5、1、5 RPS 均能恢复，不设正转速下限。

必须区分：

- 有充分观测支持接近不转：保留接近 0 的候选值，方向未分辨。
- 有明确旋转：输出转速及有向单位轴。
- 观测不足、退化或模型不一致：输出空值，不能用 0 代替。

近零方向判定使用 `2 × angular_threshold / (2π × observed_span_s)` 作为工程分辨阈值，并要求恒等模型也有足够内点。这不是统计置信区间，不把候选转速强制归零。实际数据尚无独立标定的零转速真值样本。

“至少连续三帧”的输入筛选与“至少三个旋转窗口”的整组一致性检查是两层规则。20 ms 窗口每 10 ms 滑动；原先两侧分别以各自第一条轨迹为窗口起点。本轮统一到同一次发球的共同时间网格。窗口边界改变会影响离散内点阈值和状态，不能解释为新增数据或精度已经提升。重叠窗口并不独立。

第 04 次的残差只能证明部分观测不符合当前刚体球面模型；不能单凭残差区分错关联、簇中心漂移、球心/半径偏差或其它成因。审核视频叠加模型球轮廓和真实短轨迹，便于人工逐帧复核。

## 联合建模

每次发球独立处理；两个相机使用 manifest 微秒时间对齐，同一短窗口共享一个角速度 `ω`。各自的同标记时间对应点提供球面方向约束：

```text
R = R_F59_to_F3E
F3E: s(t+Δt) ≈ Exp([ω]× Δt) s(t)
F59: s(t+Δt) ≈ Exp([Rᵀω]× Δt) s(t)
```

这不要求把两台相机内部的 track_id 当成同一个标记。两个视角的点对映射到共同坐标后进行有预算的 RANSAC，再用均衡视角权重的鲁棒非线性优化求同一个 `ω`；最后在各自原相机坐标中计算内点和重投影误差。两侧点数不同不会直接转成权重优势，拒绝的窗口和原始独立拟合均保留。

当前联合门槛包括：共同观测时段至少 2 ms、至少三个共同观测时刻、每侧至少四个内点、较强侧内点比例至少 0.70、较弱侧至少 0.35、两侧均衡平均至少 0.70，以及条件数和重投影误差检查。它们是工程参数，不是精度保证。

联合窗口不足时，保留分别自洽的单视角候选；若两侧转速相对差超过 20% 或映射后有向轴差超过 20°，保持未确定。否则优先稳定窗口较多的视角回退，其次比较可靠球轮廓下的已观测帧数。候选数值、选择规则及替代视角均写入 JSON，回退结果不标成双视角测量。

## 相机方向与验证边界

当前缺少实测相机外参，不能直接相加两侧的角速度。实验性方向配准从 02、03、07、08、09 的同时可用轴向中估计一个正旋转矩阵。每次目标发球的相机方向均用其它发球估计，目标自身不参与；04、05 没有参与相机方向估计。

按整次发球留出后的轴向预测误差为 7.15°、3.32°、6.02°、9.48°、6.27°。这些数值说明目前数据能被相近的相机方向解释，并非物理方向误差的标定结果。正式实测旋转矩阵可通过 `--orientation-profile` 替换，字段为 `camera_to_reference.F3E/F59`，都必须是正交且行列式 +1 的 3×3 矩阵。

转速及方向仍依赖球心/半径、正交投影、标记簇作为固定球面点、短时恒定角速度和源时间同步假设。不同视角不能从未知身份的相似簇直接三角化。当前输出相机坐标中的有向轴和前表面运动箭头；世界意义的上旋/下旋/侧旋仍需世界竖直、飞行方向和姿态映射。本批发球 RAW 的时间完整性尚未验证，见 [逐事件时间说明](SPIN_TIMING_ACCEPTANCE.md)。

## 运行与产物

```bash
bash scripts/pingpong.sh run serve-spin --output output/serve_review_new
# 使用实测相机方向：
bash scripts/pingpong.sh run serve-spin \
  --orientation-profile /path/to/camera_orientation.json --output output/serve_review_calibrated
```

输出包含 7 段按源时间对齐的双视角 MP4、7 张配对图、7 张转速/两侧内点比例图、逐次发球汇总 CSV、逐窗口 CSV、完整 JSON 和可选择发球的离线 HTML。25 FPS 只用于慢放；视频保留源时间戳，某视角缺原图时显示空面板，不重复上一帧冒充观测。短线只显示已经观测到的同一连续轨迹段。
