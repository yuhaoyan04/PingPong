## 已修复的时间与异常处理

1. `synchronized_windows` 输出严格的半开区间 `[start, stop)`，并保留 SDK 已读出的后续边界事件；不在相邻不重叠窗口重复计入边界。重叠窗口共享事件是设计行为。
2. 时间修正先转有符号整数，再校验范围，避免负偏移与 uint64 运算产生错误。校验修正后的时间不会下溢或超过有符号范围。
3. RAW 读取、球体精化、相关裁剪/审核入口保持原始事件顺序；遇到时间倒序明确报错，不再通过排序抹掉异常。流式窗口也检查跨批次倒序；非重叠批次检查事件是否越过请求区间。
4. 球体局部搜索没有返回任何圆时记录种子回退，避免取空候选列表导致异常。
5. 更新旧文档中的“发球 RAW 尚未上传”状态；导出 clip 的单独审核不再推断 RAW 是否已上传。

独立 EVT3 审计仍保留异常计数以供诊断；几何求解入口拒绝异常，两者职责不同。旧实验工具并非全部重构。新检查不会重写历史事件、图像或结果。

本次 RAW 已核对总计 547,522,433 个事件，没有负相邻间隔，最小正间隔为 1 μs，也存在大量同时间戳事件。1 μs 是时间量化尺度，不是已标定的时钟精度。每路参考画面到其 RAW 的时间映射已验证；两路物理同步仍无独立触发证据，不能仅凭相同时间标签宣称同步。

## 训练与数据增强对照

每个相机做 train01→holdout06、train06→holdout01。每次从相同预训练权重开始，固定 150 epoch，单通道、相同种子和优化器，训练期间不使用留出帧验证、选模或提前停止，保存最终 EMA `last.pt`，不生成 `best.pt`。原始人工标注与图像哈希在训练后再次核对。

温和增强只改变检测器训练图像：平移 ±5%、缩放 ±10%、50% 水平翻转；不改事件时间、不改离线转速观测，不使用色彩扰动、mosaic、mixup、人工拼接标记或自动负标签。原配方保持全部增强关闭。

上述帧均来自同一次录制，邻近帧强相关，只有两次标注发球，没有独立录制测试和确认空帧。这个实验衡量不同发球间的诊断性迁移，**不是现有全量训练模型的测试精度，也不是最终独立泛化验收**。本轮已查看的留出集后续只能作为开发诊断，最终需冻结新的录制测试集。分组原则参照 [Ultralytics 视频/多相机分组说明](https://academy.ultralytics.com/courses/dataset-readiness-for-yolo/split-the-dataset-correctly)。

## 转速权重与鲁棒性对照

原做法每个时间点对贡献相同；长轨迹及其多个 lag 会提供更多相关约束。新选项 `pair_weighting="cluster_equal"` 将同一相机中每个簇的总点对权重归一，再在双视角求解中归一每个相机的总权重。RANSAC、鲁棒目标、内点比例和条件数均使用一致权重。

优化目标是 `sum_i w_i * rho(||residual_i||²)` 的逐分量 soft-L1，而不是把残差乘 `sqrt(w)` 后套同一 robust loss；后者还会改变异常阈值。本轮对损失一、二阶导数做有限差分测试，求解保留恒等旋转候选。相关 API 见 [SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)。

真实数据对照严格固定：v10 平滑 CSV 的 1,781 个观测、106.67 px 的基准球半径、20 ms 窗口/10 ms 步长、相机相对方向。簇均衡对若干发球几乎不改数值，但第 03 次发球联合可用窗从 3 减到 1，第 09 次从 2 增到 5；不能根据有效窗数量选择算法。

再从原基准联合有效窗中逐个移除完整标记簇，用剩余簇重拟合，并预测被移除的簇。只在原联合共同支持时段内取点，每相机至少原有三个簇；每种方法 79 次重拟合，原权重 73 次可用，均衡权重 51 次可用。共同可用的 50 次对照，留出簇预测误差中位数为 **1.81 px → 1.95 px**。这些窗和点对仍相关，结果是敏感性诊断，不是统计置信区间或物理精度。

合成测试证明均衡可抵抗一个被重复放大的坏簇，但真实数据中短而嘈杂的簇也可能被过度放大。因此默认继续 `uniform`；新选项保留供后续按质量限权的试验使用，不按预期业余转速调整半径或整体缩放转速。

三帧连续只保证追踪筛选。500 μs 步长下三帧仅覆盖 1 ms，现有 186 段中 27 段短于 2 ms；旋转求解还需足够观测数、点对、跨度、可靠球几何及良好条件数。没有解时输出未知；不把缺观测当作零转速，也不跨段凑三帧。

## 优先推进的下一轮

1. **补观测真值与负样本**：审核本轮难例，标记球心/半径、稳定物理标记中心；对可确认无标记的球、球缘噪点和纯背景加入明确负标签。未标注帧不得自动充作负样本。
2. **中心定位优于继续加重平滑**：在检测框内跟踪局部纹理或稳定角点，使用极性、事件年龄和形变估计定位不确定度；对比 bbox 中心、加权中心、模板中心。区域扩散导致中心漂移，单纯滤波只能缓解。
3. **时间与空间标定**：共同闪光或触发验证时钟偏移/漂移；对当前 1280×720 分辨率、实际镜头及相机序列号做内外参标定，再将相机局部方向变换到球桌坐标系，可靠区分上/下旋和侧旋。
4. **短窗与多尺度积累对照**：对同一 RAW 和同一标注分别积累 250/500/1,000 μs，检测器对新图像域需重新评估；比较漏检、中心误差、轨迹持续性、留出簇预测误差，不只看检测框数量。
5. **物理转速验收**：用编码器/可控转台或独立高速视频提供 0、5、10、20、40 转/秒等真值，包含正反方向与不同转轴；以新录制冻结测试集统计转速与有向轴误差。量程应按实际设备确定，不作为算法拟合先验。

以上是建议的后续实验，未冒充已经获得的新标注或物理标定。当前人工审核页含 62 张待审核难例，支持本地记录“需补标、确认空帧、不确定、球几何问题”，导出 JSON；不会自动修改训练数据。
