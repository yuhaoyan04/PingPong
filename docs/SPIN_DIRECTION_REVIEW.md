# 三组结果、独立转速与局部方向

审核入口为 `output/latest_observations/review.html`，当前结果目录为 `output/track_continuity_v16/`。七段视频只保留三列：原始结果、球心与半径优化、球几何与标记中心组合优化。组合版新增追踪续接，见 `CONTINUITY.md`（仓库说明为 `docs/TRACK_CONTINUITY.md`）。原始结果沿用原来的追踪和平滑；三列使用同一源时间。仅标记中心优化及中间实验的结果不再保留。

## 两路独立转速和系统总转速

每列顶部显示系统总转速，F3E、F59 两行分别显示各自独立求解的转速，单位为转/秒。独立结果由该相机的多个标记共同拟合一个刚体旋转模型；不是把系统值复制到两侧。

系统优先使用双视角共享的 SO(3) 旋转拟合，以相对相机旋转矩阵统一角速度坐标；不会简单平均两个转速数值。联合拟合不可用时，允许明确标注来源的单侧回退。两侧独立转速差超过两侧均值的 20%（至少 1 转/秒），或转换到同一坐标系后的有向轴相差超过 20°，则阻止冲突的单侧回退，系统显示 N/A。有效的联合鲁棒拟合可以排除单侧误配，因此独立候选分歧时仍保留联合结果，同时显示分歧提示。

只在当前源时间确实存在该拟合所使用的观测时显示数值，不跨缺口沿用旧值。优先使用共同的时间锚定窗口；失败时允许仍覆盖当前观测的最近有效邻窗，避免显示切窗导致已有拟合提前消失。选择不参考转速大小，实际窗口 ID 逐侧记录。不足显示 N/A；有近零旋转证据时才显示近零，方向分辨不足时不画箭头。没有按业余发球的预期数值压低转速或设置非零下限。

`frame_rates.csv` 提供逐帧两路转速、系统值、来源及分歧提示；`frame_values.json` 另含角速度、有向轴、相机变换后的系统方向。七组 `plots/*_rates.png` 对应三列各自的两路与系统曲线。

## 方向检查与修复

相机坐标定义为 x 向右、y 向下、z 远离相机，可见半球的 z 为负。旧箭头使用球正前方中心的投影速度 `(-ωy, ωx)`。它的符号符合这个坐标约定，但忽略标记深度和绕视轴分量，不能代表任意标记位置的局部运动；整体翻转角速度会更不符合轨迹。

新版对每个标记的球面位置 `s` 使用有限旋转 `Exp([ω]× Δt) s`，取 0.5 ms 后的图像投影方向。其瞬时切向速度为 `ω × s`。青箭头来自该视角独立模型，橙箭头来自系统模型转换到该相机后的角速度。两台对向相机的有向轴符号可以不同，这是坐标变换的结果。

箭头长度为方便观察适当放大；未来投影只是方向提示，不写入真实轨迹。原标记 ID、真实观测点及轨迹仍保留。每个箭头先与相邻真实观测比较：球面旋转残差大于 0.035 rad、观测位移小于 0.75 px、模型位移小于 0.25 px，或局部方向夹角大于 45°时隐藏；缺少可靠球边界、未来点进入背面或投影太小也不画。不会为迎合单个抖动点翻转角速度。

方向修复阶段的组合版同窗内点诊断中，旧正前方代理方向误差中位数约 3.78°，局部有限旋转约 2.10°；正常符号的前向投影误差中位数约 1.17 px，整体取反约 26.23 px。本轮追踪续接后重新生成的具体记录见 `direction_audit.json`。这些点参与了同一拟合，窗口及不同时间跨度的点对也有关联，因此这些数字只支持方向实现的一致性，不能当作独立转速或方向精度。

逐点显示或隐藏的统计见 `presentation_summary.json`，完整记录见 `local_direction_checks.csv`。这项显示门控没有修改已求解的角速度数值。

## 保留范围与运行方式

`output/track_continuity_v16/` 保存三组有效轨迹、三组旋转报告、七段新视频、逐帧数值和检查记录。`output/observation_refinement_v14/` 仅作为两组优化的重建输入缓存，保留新裁剪、球几何、组合定位诊断及导出；`output/observation_raw_measurements/` 保留可复用的逐帧 RAW 边界测量。清理列表见本轮 `cleanup_manifest.json`。

RAW、最新标注数据、两台相机的生产模型、原始观测及原基线仍保留。没有清理其它任务的输出，也没有把优化候选替换为生产默认模型。

项目根目录运行：

```bash
bash scripts/pingpong.sh run refine-observations \
  --output output/observation_new \
  --measurements-from output/observation_raw_measurements
bash scripts/pingpong.sh run review-observations \
  --source output/observation_new --output output/spin_new
```

默认只生成球几何、组合两种优化，审核时加入原始结果。`--include-marker-only` 仅用于有意重做独立消融实验，审核视频仍展示三列。审核工具自动校验轨迹哈希、求解缺少的旋转报告、生成方向审计、视频、说明与 ZIP；已有视频文件不会重复编码，修改绘图逻辑时应使用新输出目录。

物理同步、实测相机内外参和独立转速真值仍未完成。系统方向当前属于相机局部坐标，不能宣称已精确标定球桌坐标的上旋、下旋或侧旋。此次修复解决局部方向呈现、独立数值展示和冲突回退，不代表完成物理精度验证。
