## 标记中心：追踪固定参考纹理

原位置来自 Kalman 处理的 bbox/光流中心，随后做鲁棒曲线平滑。框内区域扩散、收缩或一侧事件增多时，bbox 中点可能漂移，即使框仍然正确覆盖标记。

新方法在每个原连续段内选择纹理足够、尽量靠近段中间的参考帧，把该帧的中心作为固定纹理参考。用未过滤极性图构造 ON/OFF 有符号对比度图，在参考框内检测角点，通过带初始位移的金字塔 LK 做参考帧到当前帧的直接匹配，并检查反向匹配。之后用 RANSAC 局部仿射变换搬运参考中心，允许局部旋转、尺度和轻度形变。

角点按确定的空间顺序分成拟合、门控、诊断三组。诊断角点不用于估计变换或决定是否接受修正。接受条件包括足够角点与内点、前后向误差、特征分布、仿射尺度与旋转范围、门控误差改善、最大中心修正 8 个裁剪像素。失败时保留旧中心，不强制坐标单调，不补新观测，不跨原 ID 关联。定位后沿用相同配置的鲁棒三次平滑，仅执行一次。

与原 tracker 每帧重新选角点并取平移中位数不同，本方法对同一固定参考纹理做直接配准，并允许局部仿射变化，减少逐帧 bbox 形变对位置的牵引。算法依据可见图像运动，不用转速拟合结果反向修改观测。API 参见 [OpenCV 光流与图像配准文档](https://docs.opencv.org/4.x/dc/d6b/group__video__track.html)。

重要限制：参考中心仍起于参考帧的框中心，它不等于已人工标定的物理墨点中心。若一个簇含多个物理点、纹理消失或对应错误，局部模型也会失败；当前通过门控回退，不能宣称绝对物理点定位已解决。

## 球几何：RAW 边界测量与连续轨迹

球心和半径不是只修改测转速时的一个系数。原裁剪已按旧球轨迹逐事件去平移、去尺度变化；因此本轮从实际 RAW 窗口重建新裁剪，使用新轨迹对每个事件做补偿，保持原时间标签、1 ms 积累窗、500 μs 步长、相机去噪配置及 1.2 倍裁剪边距。

具体过程：

1. 先按原轨迹将 RAW 边界事件补偿到当前时刻。在原圆附近的环带中分 72 个角度扇区，每个扇区提取一个径向密度峰，降低单条密集弧线、重复事件对拟合的支配。
2. 三组交错扇区分别用于圆拟合、门控和未参与决策的诊断。RANSAC 加鲁棒几何最小二乘估计球心及半径，并检查角度覆盖、条件数、独立扇区拟合一致性和搜索边界。不是把所有事件都强行贴到圆上。
3. 对合格圆测量建立连续的局部二次“相对原轨迹修正”模型：邻域 ±3 ms，至少五个测量，测量跨度至少 2 ms，不外推，鲁棒残差尺度 0.6 RAW px。原圆已经很好、无需明显修正的帧也参与约束，避免只挑大修正帧。
4. 当前边界短暂不足时，允许邻近合格测量约束下的短缺口几何估计，明确标记 `short_gap_temporal_geometry`。当前弧线强烈矛盾时，保留连续裁剪坐标，同时将该观测排除出旋转输入，不突然改回旧圆造成虚假运动。
5. 连续模型开始、结束或失去支持时设显式边界；完整 1 ms 窗口混用两种几何的观测不进入转速输入，也不跨这些边界凑三帧。原有 `fallback_unverified` 不自动升级为可靠球检测。

鲁棒圆拟合使用 [SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)；模型没有业余发球转速先验，不按期望 RPS 选择半径，也不裁剪转速数值。

搜索仍依赖原粗球位置，球心修正上限为原半径的 18%，半径变化上限 20%；这不是任意偏离位置的全画面重检测。第 05 次发球 F3E 仍缺可靠球边界，继续输出不足，不能借平滑制造有效数据。

## 运行与文件

从项目根目录执行，输出目录必须是新的：

```bash
bash scripts/pingpong.sh run refine-observations --output output/observation_new
bash scripts/pingpong.sh run review-observations --source output/observation_new --output output/spin_new
```

默认使用实际发球 RAW 的已核验范围缓存 `/tmp/pingpong_raw_sync_cache_v9`。若缓存缺失，工具从项目 `data/master_DSP01F1FFF3E.raw`、`data/slave_DSP01F1FFF59.raw` 重建，并比较独立 EVT3 与 SDK 的范围序列；也可指定 `--cache`。这是本批既有轨迹的改进入口，新录制仍应先完成球检测与源清单。

若复用本轮逐帧圆测量以缩短时间：

```bash
bash scripts/pingpong.sh run refine-observations \
  --output output/observation_new \
  --measurements-from output/observation_raw_measurements
```

复用会检查原 manifest 哈希、原圆轨迹和测量参数，并重新核对 RAW 裁剪。`--geometry-model` 可选 `framewise`、`continuous_strict`、`continuous_bridge`，分别对应早期逐帧候选、严格逐帧门控连续模型、最终短缺口连续模型；默认最后一种。v12/v13 中间结果已清理，仅保留可复用的 RAW 圆测量。默认只生成球几何及组合两组，开发消融需要显式传入 `--include-marker-only`。

重建输出：`dataset/` 为新裁剪及源清单，不复制训练标签；`tracks/` 包含全观测、合格连续段及仅平滑一次的有效 CSV；`geometry/`、`localization/` 保存接受/拒绝理由。新审核目录中的 `spin/`、`tracks/` 只保留三组报告及有效轨迹；`frame_values.json` 对应视频每个源时间的独立、系统 RPS 和方向。审核包排除重建图像数据集与 RAW，保留视频、诊断、CSV、配置及审核说明。

新增合成测试覆盖噪声圆、密集弧线重复、短弧/随机噪声拒绝、已知仿射形变下的中心恢复、无纹理拒绝、极性位置、短缺口连续性、边界矛盾排除、源坐标变换及几何混合窗口切段。真实数据仍以独立诊断与人工视频审核为主。

定位与几何阶段完整测试为 270 通过、1 跳过，后续方向改进阶段为 279 通过、1 跳过。最新七段视频共 1,343 帧均实际解码检查；浏览器及原输入完整性验证记录保存在最新审核目录。新几何可从保留的 RAW 圆测量复现。
