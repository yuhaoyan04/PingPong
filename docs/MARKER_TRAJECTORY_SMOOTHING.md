# 从 bbox 中心轨迹到角速度，以及新增的曲线平滑

审核入口 `output/latest_smoothing/review.html`，实际目录 `output/trajectory_smoothing_v10/`。7 段视频按同一原始时间展示两相机、平滑前后轨迹、同窗转速与方向，支持前后逐帧。原始检测框、轨迹 ID、观测来源、帧数与时间均保留。没有新增检测或填补缺帧。

## 角度来自三维球面旋转模型

YOLO 框住的是一块标记区域。追踪器通过高/低置信度关联、经验证的 LK 光流和匀速 Kalman，输出该簇的中心。原始球平移与尺度变化已在事件裁剪生成时补偿；旋转信号留在裁剪内。当前簇中心仍只是物理标记点位置的代理。

在 256×256 裁剪中，球心为 `(128,128)`，源裁剪倍率 1.2 对应名义半径 `R=128/1.2≈106.667 px`。不能把标记框自身的宽度当作球半径。以弱透视和可见前半球为假设，把像素中心 `(u,v)` 提升为单位球面点：

`X=(u−128)/R, Y=(v−128)/R, Z=−sqrt(1−X²−Y²)`。

相机坐标 x 向右、y 向下、z 远离相机。对同一 ID、同一连续段内的观测，使用真实微秒时间差，当前通常为 0.5、1、2 ms。每个短窗口寻找一个公共三维角速度向量 `ω`，使所有对应尽量满足：

`s(t+Δt) ≈ Exp([ω]× Δt) s(t)`。

指数映射表示绕 `ω/||ω||` 旋转 `Δθ=||ω|| Δt`，不是把二维路径按直线计算。`转/秒=||ω||/(2π)`，`转/分=60×转/秒`；轴向保留符号，以右手规则解释。例：40 转/秒、相隔 500 μs，对应球转角 7.2°。近零旋转允许输出近零幅值，但轴方向可能不可分辨。

单个球面点的 `acos(s0·s1)` 是它在球心看到的位移夹角，通常不等于球的转角。若旋转轴是单位向量 `a`，则 `cos(α)=cos(Δθ)+(1−cos(Δθ))(a·s0)²`；点越靠近转轴，位移越小。因此不能用一个点的二维转弯角或球心夹角直接除以时间。需要多个点、多帧共同约束转轴与转速，并拒绝退化几何。

实际求解在 20 ms 窗口、10 ms 步长中进行，先用 RANSAC 找一致的刚体运动，再用 soft-L1 稳健优化。点对数量、真实观测数、时间跨度、内点比例、重投影残差、条件数和混叠风险共同决定窗口是否可用。三帧是保留轨迹的最低条件，不保证能求出三维旋转。双视角不假设两路的标记 ID 一致，而是在相机相对方向变换后共同约束一个 `ω`；当前相对方向与物理同步仍未完成独立标定。

## 新增的鲁棒局部三次平滑

原追踪器已有因果匀速 Kalman，bbox 扩散仍可能推偏观测中心，曲线加速也可能让匀速估计滞后。现在在旋转求解前追加局部曲线处理，实现于 `trajectory_smoothing.py`：

1. 只在同一相机、发球、轨迹连续段及可靠球轮廓子段内处理。回退球轮廓切断平滑上下文，不把它的偏差传给两侧可靠数据。
2. 当前 500 μs 采样下取前后 1.5 ms，典型 7 点；端点只从本段内部扩展到至少 7 点，不生成段外观测。3–6 点保留已有 Kalman 坐标。
3. 使用真实相对微秒时间，分别拟合 `x(t)=a0+a1τ+a2τ²+a3τ³` 与 `y(t)`。曲线可以弯曲、加速与真实转向，不强制 x/y 单调，也不把点投影到预设旋转模型。
4. 邻域内通过 Huber 迭代降权大残差，加入杠杆修正，降低端点“解释自身”的影响；光流/低置信度观测与框形状突变的权重较低。形状来自追踪器框尺寸，不是假称新的物理标记尺寸测量。
5. 单段若提议修正超过 8 px，或越出名义球面，整段/子段保留原值，不裁剪出一条假路径。每点保留原坐标、修正量、权重、处理状态与原始 bbox。

局部多项式滤波思路参考 [SciPy Savitzky–Golay 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.savgol_filter.html)；异常点降权参考 [SciPy 稳健最小二乘损失说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)。这里实现的是带来源/形状权重及 Huber 迭代的局部三次拟合，不是直接调用普通 `savgol_filter`。

## 当前数据的结果

原始与处理后均为 1781 个观测、186 个连续段。其中 1414 个点追加平滑，其余因短段或球轮廓不可靠等保留原值。中心修正以 256×256 裁剪像素为单位：中位数 0.315 px，95% 不超过 1.740 px，最大 7.975 px。

按相邻步与两侧步的方向一致性作工程诊断，局部反向步总计 9→4；完整可靠球轮廓上下文内为 4→0。剩余 4 处均位于不参与旋转点对拟合的回退轮廓区，保持原样供审核。这是诊断定义下的现象计数，不是真实误检/转速精度真值。

平滑前后固定名义半径、相机相对方向、原始时间、轨迹身份，以及视频同一时刻选中的旋转窗口和数据来源。某个后处理窗口不再合格时显示 N/A，不能换一个窗口来掩盖失败。下表只比较两版都数值可用的相同联合窗口，不代表整次发球的稳定性结论：

| 发球 | 原轨迹中位 RPS | 平滑后中位 RPS | 有向轴变化中位数 |
| --- | ---: | ---: | ---: |
| 02 | 34.35 | 34.16 | 0.59° |
| 03 | 40.37 | 40.51 | 0.24° |
| 04 | 42.20 | 40.04 | 0.89° |
| 05 | 无共同可用窗口 | 无共同可用窗口 | N/A |
| 07 | 22.71 | 22.34 | 0.80° |
| 08 | 40.40 | 40.83 | 0.92° |
| 09 | 39.46 | 39.50 | 0.40° |

窗口通过数不是精度指标。例如 08 的数值可用联合窗口由 2 减至 1，原轨迹与新轨迹均保留，不能只展示新增通过的窗口。`original_observation_reprojection.csv` 还把两版旋转模型作用于同一批未平滑的原始点对；这些点不是独立真值或留出测试，残差更低仍不能证明物理精度更高。

合成测试验证 0/20/40/80 转/秒的角速度幅值与有向轴保持、0–80 转/秒曲线形状、孤立跳点降权、真实曲线转折、短段保留、过大修正回退、回退轮廓隔断、整数时间精度及半径对照不改变平滑像素。当前测试不能替代已知转速实物检验。

## 默认流程与复现

`config/offline_marker_spin.json` 已启用 `trajectory_smoothing`；`spin`、逐次双视角拟合与半径比较均在统一 `read_tracks` 入口应用。转速审核、逐次发球/半径视频以及运动可视化读取相同的有效坐标。源 CSV、旧视频和旧报告不覆盖。要保留原轨迹求解，可在独立配置中设 `trajectory_smoothing.enabled=false`。

完整参数在 `config/marker_trajectory_smoothing.json` 与代码默认值一致；需要修改默认运行时的参数，应把相应键写入 `offline_marker_spin.json` 的 `trajectory_smoothing` 对象。显式已平滑 CSV 再次运行时须关闭此层，避免重复滤波；代码会拒绝对已处理点叠加平滑。

```bash
bash scripts/pingpong.sh run smooth-tracks --output output/smoothing_new
bash scripts/pingpong.sh spin --output output/spin_smoothed_new
```

审核目录主要文件：`smoothed_rotation_tracks.csv`（原中心、新中心、原框与每点权重）、`segment_metrics.csv`、`matched_spin_windows.csv`、`original_observation_reprojection.csv`、`local_reverse_diagnostics.csv`、`before_spin.json`、`after_spin.json`、7 个 MP4、14 张轨迹图、`validation.json`。

平滑能抑制短暂中心噪声，不能恢复已经换错的物理标记身份，也不能修正持续的簇形变、错误球心/半径或同步偏差。较长时间的中心偏移需要利用簇内稳定角点/事件结构重新定位。物理方向分类仍需要世界坐标与飞行方向；当前箭头只表示相机可见前表面的运动。
