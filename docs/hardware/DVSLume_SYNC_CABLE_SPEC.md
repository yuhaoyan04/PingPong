# DVSLume 双机主从同步线束规格

依据《DVSLume 使用手册(1).pdf》第 7 节“多 DVS 同步（主从模式）”官方接线图：

| 主相机端 | 从相机端 | 功能 |
|---|---|---|
| pin 3 | pin 3 | GPIO_INOUT / SYNC，1 MHz 主从时钟 |
| pin 6 | pin 6 | GND，同步信号参考地 |

pin 1、2、4、5：NC（两端均不装端子或不导通）。

## 下单描述

制作一条 DVSLume 相机对相机的 6-pin P7 同步线。两端连接器与 DVSLume 的 6-pin P7 接口匹配，直连 pin 3 到 pin 3、pin 6 到 pin 6；pin 1、2、4、5 两端均 NC。请按针脚位置制作，不按线色推断，并提供成品通断表。

建议 pin 3 与 pin 6 使用双绞线，线长尽量短，并使用带锁紧结构的相机端连接器。

## 禁止接法

不得使用六芯全直通线连接两台分别由 USB 供电的 DVSLume；尤其不能把两端 pin 1（VCC_OUT，5 V 电源输出）相连。
