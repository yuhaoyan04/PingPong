# serve05 的转速缺失与追踪续接

最新审核：`output/latest_observations/review.html`。本轮结果为 `output/track_continuity_v16/`，仍只展示原始结果、球心与半径优化、组合优化三列；组合版加入追踪续接。七次发球都重放了相同模型的冻结检测输出，未重新训练 YOLO，未降低出生阈值或移除球缘过滤。

## 为什么有标记轨迹却没有转速

二维中心轨迹首先提供图像上的运动。要把它变成球体转速，还需可靠的球心、半径及可见球面位置，并且同一物理簇的运动应符合共同刚体旋转。框中心受形变或局部事件分布影响时，也可能移动而非真实墨点旋转。

连续三帧是追踪导出的最低要求，按本批 500 μs 步长仅跨 1 ms；它不等于旋转拟合已经足够稳定。现有拟合仍要求至少 6 个不同观测、8 个有限旋转点对、至少 2 ms 的时间跨度，以及内点比例、几何条件和投影残差合格。不同点对和重叠窗口彼此有关联，数量不能当成独立样本量。

serve05 具体存在三类原因：

1. F3E 有轨迹的 23 帧中，仅 10 帧具有原球边界支持，另 13 帧的球几何不足。10 帧里还有 1 帧与其它可靠球面观测不连续，不能组成有效点对。因此只有 9 帧对应可用转速，其余二维轨迹继续显示。RAW 边界圆检查也没有通过，不能简单把这些帧改成可靠球面。
2. F59 原来有 11 帧能被同一个有效拟合覆盖，但旧显示只展示 7 帧：时间走到另一个失败窗口时，忽略了仍覆盖当前真实观测的有效邻窗。这是显示选择造成的额外缺失，本轮已修复。
3. 原追踪器要求待确认轨迹下一帧继续有高置信检测；一帧漏检就立即删除。已确认轨迹的光流若依赖上一帧，而上一帧纹理暂时差，也容易切段。serve05 F59 原来末段在第 121 帧缺少图像证据，被拆成第 116–120、122–131 帧两段。

## 改进方法

待确认轨迹允许最多 6 帧的确认时间，期间可以用核验光流或低分检测保持状态；仍须累计两个高置信命中才确认，单次高分后仅有纹理不能出生为有效输出。确认轨迹优先匹配检测；待确认轨迹的第二次高分关联不使用可能歧义的光流位置抢占已有轨迹。

原光流失败后，尝试以运动预测作为 LK 初值，并做反向一致性、角点数量、局部外观、事件数量、位置及球缘检查。上一帧缺纹理时，可以从最近有真实证据的图像恢复到当前图像，跨度最多 1.5 ms。仍然失败的当前帧只算预测保持，不写入转速观测；恢复不补造缺失帧，也不跨已终止 ID 重关联。

serve05 F59 的第 121 帧现在由核验光流支持，末段成为第 115–131 帧连续观测；它不是把旧预测帧直接当作真值。同时找回了此前因确认过快失败而丢失的较早段。所有轨迹仍经原连续三帧筛选、保留的 RAW 球几何筛选、固定纹理定位和一次鲁棒平滑，再重新求解转速。

显示优先采用按时间选定的锚定窗口；该窗口不可用时，可选择仍覆盖当前时间且包含当前真实观测的最近有效重叠窗口。选择只考虑时间及数值有效性，不根据转速大小挑选；不跨窗口边界外推，不在没有当前观测时维持旧值。两路与系统各自的实际窗口 ID 写入 `frame_rates.csv` 和 `frame_values.json`。画面增加缺失原因说明。

## 运行和检查

项目根目录：

```bash
PYTHONPATH=src:tools/yolo .venv/bin/python tools/refine_track_continuity.py \
  --prior output/spin_direction_review_v15 --output output/continuity_new
bash scripts/pingpong.sh run review-observations \
  --source output/continuity_new --output output/continuity_new
```

也可通过 `bash scripts/pingpong.sh run refine-continuity` 运行，工作流会设置 Python 导入路径。上述保留的 v15 数值缓存用于复现本轮前后统计；开始下一轮比较时可将 `--prior` 改为 `output/latest_observations`。冻结检测的模型哈希、检测阈值、时间戳逐组校验；原始数据、模型及球几何缓存保持不变。`continuity_provenance.json` 保存模型和检测缓存哈希，`tracking/` 保存每帧来源、光流方法、确认和删除原因，预测帧明确标记且不进入有效转速 CSV。

新增测试覆盖漏检期间待确认状态、一次高分不能靠纹理自行确认、最近真实图像恢复且空帧仍为预测、已有 ID 优先匹配，以及有效邻窗覆盖和缺帧不保持数值。完整测试为 284 通过、1 跳过。
